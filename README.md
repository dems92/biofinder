# Conseil compléments BiotechUSA

Aide-mémoire vendeur : analyse de la situation d’un client, fiches produits et nutriments, comparaison de deux produits, préférences alimentaires (végétarien, vegan, halal).

## Lancer en local
```
npm install
npm run dev
```

## Mettre en ligne
Le dépôt est relié à Vercel : chaque modification poussée sur la branche `main` redéploie le site automatiquement.
